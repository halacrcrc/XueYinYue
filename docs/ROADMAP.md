## 二、扩展方向（五个批次，按优先级）

### 批次一：现有章节加深（+12–15 课，教学主线优先）

| 章 | 新增课 |
|---|---|
| 二 节奏 | 附点与休止符；三连音与切分；3/4 与 6/8 感受；swing 律动；更多风格节奏型（雷鬼 / funk / 波萨诺瓦）；音序器任务关卡（听节奏型→复刻） |
| 三 音阶 | 关系大小调 vs 同主音大小调；布鲁斯音阶；五度圈静态预览（为第七章铺垫）；移调练习题（build 变体：把旋律移到 G 调） |
| 四 音程 | 音程转位；旋律音程 vs 和声音程（听感差异专项） |
| 五 和弦 | 七和弦家族（大七 / 属七 / 小七 / 半减）；sus2 / sus4 挂留；和弦转位与键盘把位；琶音与分解和弦 |
| 六 和声 | 终止式（正格 / 半终止 / 变格）；副属和弦入门（V7/vi） |

### 批次二：新章节（+2 章 ≈10 课）

- **第七章 调与五度圈**：互动五度圈工具（SVG 环，点击转调、显示调号）；调号识别练习；近关系调与转调手法（关系调 / 属调 / 平行调）
- **第八章 旋律写作**：动机与模进；乐句的"问与答"（antecedent/consequent）；给 1–5–6–4 写旋律的实操工作流（在音乐乐园乐器台上完成小作业）

### 批次三：练习系统扩展

- 新题型（先 exercise.rs + 单测，再接 UI）：**听节奏**（播放节奏型→音序器上复刻）、**旋律听辨**（3–5 音哼唱选谱）、**大小调听辨**、**和弦进行听辨**（答级数）、**指板辨认**（吉他版认音名/级数）
- **每日挑战**：跨知识点混合 10 题，计入进度
- **错题本**页面：按知识点聚合错题，一键再练
- 掌握度雷达图（按章/按题型）；成就徽章（连续 7 天 / 首个 100 分 / 全章通关）

### 批次四：曲式与编曲项目课（+2 章）

- **第九章 曲式入门**：一段体 / 二段体 / 主歌副歌结构；用音序器 A/B 段排列体验"段落感"
- **第十章 编曲实验室**（毕业项目）：贝斯线写法（跟和弦根音/五音）、鼓点编排进阶、音色搭配直觉；最终作业：**做一首 8 小节小曲**（鼓+和声+旋律，音乐乐园合奏完成，可导出 WAV 分享）

### 批次五：工具页与特色内容

- **和弦查询器 / 音阶查询器**：选根音+性质 → 钢琴 / 吉他指板 / 五线谱三视图同步
- **节拍器**（带 2/3/4 分拍与重音）
- **简谱乐理专章**：简谱的拍号、时值下划线、连音线、装饰记号（国内用户刚需，全站唯一差异化内容）
- **名曲分析系列**：公版曲目自建重建（卡农、欢乐颂、小星星变奏等），跟播放逐小节高亮
- 视唱入门（可选：麦克风音高检测，autocorrelation 实现）

## 三、优先级依据

教学主线闭环（批次一二）→ 练习巩固（三）→ 创作输出（四）→ 工具与特色（五）。每批次预计 2–4 个工作 session；批次三的每日挑战与错题本优先级最高（直接提升留存与复习闭环）。

## 四、技术注意

- 新练习题型一律先在 `core/src/exercise.rs` 实现出题与判分并补单测，前端只接 UI（职责铁律不变）
- 新交互组件（五度圈、查询器、节拍器）参照 `fretboard.js` 模式：独立组件 + 对外 set/highlight/destroy API
- 名曲分析只用自建重建（MIDI 化重录），不使用原曲音频（版权安全）
- 每批次完成后：`cargo test` 全绿 → `npx vite build` → 浏览器实测 → 更新 ROADMAP 与 HANDOFF → 提交推送（自动部署）
