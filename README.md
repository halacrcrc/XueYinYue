# 学音乐 · XueYinYue

边玩边学的中文互动乐理课 —— **Rust + WebAssembly** 做乐理引擎，浏览器原生 Web Audio 发声（真实大钢琴采样 + 经典鼓机音色），无需账号、无需后端，打开就能弹。

教学设计融合了三类经过验证的方法：**微课时结构**（一屏一概念、学完即练）、**四向练习矩阵**（看谱辨认 / 听音辨认 / 按要求构建 / 键盘辨认）、**调性练耳法**（先建立调中心再听音）——外加波形可视化，把"为什么协和"直接画给你看。

## 课程一览

| 章节 | 学什么 | 特色互动 |
|---|---|---|
| 一 · 声音与音名 | 振动、钢琴地图、音名、唱名与简谱 | 动态波形、唱名七色琴键 |
| 二 · 节奏与节拍 | 拍 / BPM / 拍号、时值、风格节奏型 | 步进音序器、跟打毫秒评分 |
| 三 · 音阶 | 五声先行、半音全音、大小调公式 | 键盘高亮、移调演示 |
| 四 · 音程 | 度数与半音、协和与不协和 | 频率比波形可视化（3:2 为什么协和） |
| 五 · 和弦 | 大 / 小 / 增 / 减三和弦 | 听辨 + 亲手搭和弦 |
| 六 · 和声进行 | 级数思维、经典进行、移调 | 七和弦点听、进行自动演奏、八调移调实验室 |
| 练耳训练场 | 调性级数 / 音程 / 和弦 | 先播 I–IV–V–I 建立调中心再答题 |

## 特性

- **乐理对错全部由 Rust 保证** —— 音程、音阶、和弦、简谱、出题与判分都在 WASM 引擎里实现，47 个单元测试全绿
- **双层声音引擎** —— 页面一打开就能发声（Web Audio 合成兜底），真实采样（大钢琴与鼓组）流式加载完成后无缝接管
- **颜色即乐理** —— 唱名七色体系（红 do、橙 re、黄 mi、绿 fa、蓝 sol、紫 la、粉 si）贯穿琴键、简谱、五线谱与课程进度，认住颜色就认住了音
- **学习进度系统** —— 掌握度算法、答错次日复习的间隔重复、连续天数、12 周热力图、每日目标；数据存本机，支持导出 / 导入 JSON，也可用 **GitHub / Gitee Gist 云同步**（首页"☁ 云同步进度"，多设备合并不丢数据）
- **设计有手感** —— 暖纸白晨光练习室视觉、Maple Mono NF CN 圆角等宽字体（中英混排统一）、VexFlow 真实雕版乐谱音符、弹簧曲线的琴键按压反馈；尊重 `prefers-reduced-motion`，触控目标 ≥ 44px

## 本地使用指南（每天怎么用）

**启动**（两种方式任选）：
- 双击项目根目录的 **`start.bat`**，浏览器会自动打开 http://localhost:5173
- 或在命令行执行：`cd D:\XueYinYue\web`，然后 `npm run dev`

**关闭**：在运行它的命令行窗口按 `Ctrl + C`（或直接关掉窗口）。应用和浏览器页面都可以随手关。

**再次打开**：重复上面的启动步骤即可——就是同一个入口，没有别的步骤。

**进度还在吗？在。** 学习进度保存在浏览器里（本机 localStorage），与命令行窗口无关：
- 关闭应用、重启电脑，进度都在
- 前提是：用**同一个浏览器**、**同一个地址**（http://localhost:5173）打开——进度按"地址"区分
- 换浏览器或清理浏览器数据会丢进度，所以首页提供了**导出 / 导入进度**按钮，建议定期导出一个 JSON 备份

## 快速开始

```bash
git clone https://github.com/halacrcrc/XueYinYue.git
cd XueYinYue/web
npm install        # 首次需要联网（含采样 CDN）
npm run dev        # 打开 http://localhost:5173
```

环境要求：Node.js ≥ 20、Rust（含 `wasm32-unknown-unknown` 目标）、wasm-pack。

## 常用命令（都在 `web/` 目录下）

| 命令 | 作用 |
|---|---|
| `npm run dev` | 编译 WASM 并启动开发服务器（热更新） |
| `npm run build:wasm` | 仅重编 Rust 核心（改了 `core/` 之后执行） |
| `npm run build` | 生产构建，产物在 `web/dist/`（全静态，可直接托管） |

Rust 侧测试：`cd core && cargo test`

## 技术架构

```
core/   Rust 乐理引擎 → WebAssembly
        note / interval / scale / chord / jianpu     乐理计算（纯逻辑，全单测）
        exercise                                      四向练习矩阵出题 + 判分
        progress                                      掌握度、间隔重复、学习日历
web/    Vite + 原生 JS（无框架）
        audio.js        双层声音引擎（合成兜底 + smplr 采样）
        piano.js        交互钢琴（点击/电脑键盘/高亮/唱名着色）
        lesson.js       微课引擎（讲解/演示/练习块渲染）
        sequencer.js    16 格步进音序器    tap-trainer.js  跟打评分
        staff.js        VexFlow 五线谱     jianpu.js       简谱渲染
        progress.js     进度存取           pages/          首页 / 练耳训练场
docs/   HANDOFF.md     交接文档（架构、API、设计规范、已知坑）
```

**职责铁律**：所有"对错与分析"只发生在 Rust（带单元测试）；JS 只做呈现、发声与存取。

## 部署（已上线）

推送到 `main` 分支会自动构建并发布到 **https://halacrcrc.github.io/XueYinYue/**（GitHub Actions + Pages，见 `.github/workflows/deploy.yml`）。手机浏览器打开同一地址即可随时随地学——注意线上与本地是不同的浏览器存储，进度各自独立，搬家用首页的导出 / 导入。

本地静态部署（可选）：`npm run build` 后用任意静态服务器托管 `web/dist/`。首次使用需联网加载乐器采样，浏览器缓存后即可离线弹奏。
